Description
This versioned research package supports the manuscript “Microbial-Inoculation Effects and Fractional Dynamics: A Study-Level Secondary Analysis with Numerical Verification”. It contains the publisher-supplied Azarbad and Junker (2024) Supplementary Table S1 workbook and a value-preserving CSV export; the reconstructed Python workflow for study-first descriptive aggregation, bootstrap summaries, missingness diagnostics and five-fold study-grouped prediction; run manifests, dependencies, derived outputs and quality-assurance workbooks; and separate scripts and outputs for the specified constant-order and variable-order scalar numerical-verification tests. Four manuscript figures are also provided. The primary source workbook is included unchanged with attribution. The original Colab notebook was not recovered, so empirical analyses are a documented reconstruction, not a bit-for-bit rerun of the historical notebook. Published lnRR and sampling-variance V fields are retained as provided; they are not recalculated from primary-study means, standard deviations and sample sizes. The empirical data do not identify biological parameters for the proposed crop–microbe–nitrogen model, nor do the scalar numerical tests validate that biological model. The project-authored Python scripts are licensed under MIT; the source data, new figures, derived outputs and documentation are licensed under CC BY 4.0. All 15 manuscript authors have provided written email approval for public release and the file-scope licence mapping; the approval register is included in the archive. See README and provenance notes for full methods, licensing and limitations.
