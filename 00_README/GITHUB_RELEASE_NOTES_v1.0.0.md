# v1.0.0 — Initial research reproducibility release

Initial versioned release of the JMPM microbial-inoculation secondary reanalysis and selected scalar numerical-validation materials.

Includes the source Supplementary Table S1, reconstructed empirical script and outputs, source-data QA, grouped study-level predictive benchmark, numerical-validation scripts/results, manuscript figures, documentation and licence mapping.

The original historical Colab notebook was not recovered. The empirical pipeline is a transparent reconstruction, not a bit-for-bit historical notebook rerun. The scalar numerical tests do not validate the crop-specific biological model.
