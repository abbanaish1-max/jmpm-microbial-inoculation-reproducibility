# v1.0.0 — Initial research reproducibility release

Initial versioned release of the JMPM microbial-inoculation secondary reanalysis and selected scalar numerical-validation materials. The package was prepared on 24 November 2026.

Includes the source Supplementary Table S1, reconstructed empirical script and outputs, source-data QA, grouped study-level predictive benchmark, numerical-validation scripts/results, manuscript figures, documentation, source attribution and approved file-scope licence mapping.

The corresponding author reports written email approval from all 15 manuscript authors for public release and the per-file licence arrangement: CC BY 4.0 for the source data, project-authored figures/outputs/documentation and MIT for project-authored Python scripts. The public approval register is included; original email correspondence is retained privately.

The original historical Colab notebook was not recovered. The empirical pipeline is a transparent reconstruction, not a bit-for-bit historical notebook rerun. The scalar numerical tests do not validate the crop-specific biological model.
